# n8n AI Lead Management & Customer Support Pipeline

This repository contains a production-ready, multi-layered n8n automation workflow designed to streamline business operations.

### Key Features Engineered:
* **JSON Payload Parsing & Webhooks:** Captures raw webhook incoming traffic from lead capture forms seamlessly.
* **Custom JavaScript Nodes:** Formatted internal logic arrays to validate data and cleanly delete or filter out duplicate CRM entries.
* **RAG System Deployment:** Connected to Supabase vector databases to dynamically pull context and resolve customer support queries autonomously.
* **LLM Fallback Strategy:** Built automatic switching safeguards between OpenAI and Claude APIs to ensure 100% uptime during network failures.
